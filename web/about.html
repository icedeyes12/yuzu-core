Why I Built This

I wanted something simple, ready-to-go, and personal. No complicated setups, no subscription fees — just a companion that works out of the box.

Inspired by platforms like SillyTavern, but stripped down to the absolute essentials. It blends a nostalgic terminal vibe with a clean, modern web UI. Sometimes you want the deep customizability of a nerd aesthetic, and sometimes you just want a seamless chat experience.

Originally created as a passion project for personal use, but hopefully, it brings a little joy to others as well.

The Tech Stack

Python Backend runtime (3.12+)
FastAPI Async web framework
PostgreSQL Database & vector storage
BYOK Architecture Bring Your Own Key for LLMs
Vite SPA Vanilla ES modules, no framework
marked.js Markdown rendering

Built with accessible, maintainable tools that prioritize longevity.
